    How it works

    Deterministic first, judge second

    1. SuiteA versioned, hashed suite of a few hundred prompts across math, knowledge, format following, truthfulness, unanswerable questions and benign requests that look risky.
    2. GenerateGreedy decoding of each checkpoint, cached per sample so a run can resume. The device and precision are recorded with the run.
    3. ScoreExact match and rule checks decide wherever a rule exists. A small local judge answers narrow yes/no rubric questions where none does.
    4. ClusterFailing answers are embedded, clustered, and labelled by the failure tag most members carry. Purity and the odd ones out are shown.
